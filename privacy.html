Privacy Policy

Last updated: November 10, 2026

n8n Juan ("the app") is a personal automation tool operated by Juan Esteban Amezquita in Omaha, Nebraska, USA. It is used only by its owner to create a private daily summary of his own Gmail inbox. This policy explains what data the app accesses and how it is handled.

1. Data the app accesses

With the account owner's permission (Google OAuth), the app accesses the following Google user data:

  • Email metadata and previews: sender, subject, Gmail labels and the short preview text ("snippet") of messages received in the last 24 hours.
  • Sending: permission to send one summary email per day to the account owner only.

The app does not read attachments and does not access contacts, calendar, Drive or any other Google service.

2. How the data is used

  • The data is used for one purpose only: to generate a daily summary of the inbox and email it to the account owner.
  • To write the summary, the email metadata and previews are sent to the Anthropic API (Claude). Anthropic processes this data to return the summary and, under its commercial terms, does not use API data to train its models.
  • The app never replies to, deletes, archives, forwards or sends email to anyone other than the account owner.

3. Sharing

Google user data is not sold, rented, shared or transferred to anyone, except to the AI provider described above solely to produce the summary. It is not used for advertising, profiling or any other purpose, and humans do not read it except the account owner.

4. Storage and security

  • The app runs on a private server (Hetzner Cloud) that is not accessible from the public internet. Access requires an encrypted SSH key.
  • Access credentials are stored encrypted. Email content is not stored in any database; the automation platform keeps short-term run logs only for troubleshooting.

5. Limited Use disclosure

The app's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Your control

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked the app stops working immediately.
